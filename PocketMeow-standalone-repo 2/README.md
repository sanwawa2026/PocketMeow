# PocketMeow 口袋主子

独立跨平台 3D 赛博宠物陪伴 App（阶段 1–3 MVP）。

## 本地运行
```bash
npm install
npm run dev
```

## 推送至 GitHub 仓库 (sanwawa2026/Pocket_Meow)
```bash
git init
git add .
git commit -m "feat: initial PocketMeow stages 1-3 MVP"
git branch -M main
git remote add origin https://github.com/sanwawa2026/Pocket_Meow.git
git push -u origin main --force
```
